# Contributing

This is a documentation/examples repository for a hosted product. The backend and infrastructure source remain private.

Good contributions: clarify a setup step; improve an accessible example; document a reproducible UI problem; correct a factual limitation; translate a guide accurately.

1. Search existing issues.
2. Open a focused issue describing one user task.
3. For docs, create a branch and edit only public guides/examples.
4. Check links, spelling, code placeholders and the actual UI labels.
5. Open a pull request explaining the problem, change and how you checked it.

No subscription, private account access or credential sharing is required. Use fictional domains/people and placeholders. Label documentation-only review versus a real connection/product test. Never upload private scans, cookies, authorization headers, email addresses, logs or secret verification files.

For vulnerabilities follow SECURITY.md rather than a public issue.
