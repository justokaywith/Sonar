# Security reporting

Do not publish exploit details, private reports or credentials in public issues.

Use GitHub private vulnerability reporting when available, or email support@pactuno.online with subject **Sonar security report**. Include the affected feature, minimal reproduction, expected/observed behavior and impact. Redact tokens and personal data.

Test only domains/accounts you own or have explicit permission to assess. Do not run denial-of-service, password guessing, invasive payloads or access other users' data. The public repository has no hosted backend source; report hosted application issues privately.
