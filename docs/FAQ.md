# Frequently asked questions

## Is Sonar free?

The hosted workspace is free within its current limits. No paid API key is needed for the basic crawler. Third-party provider integrations have their own configuration, availability and quotas; free does not mean unlimited capacity.

## Do I need an account or installation?

Basic audits work without signing in. No clone, server deployment or desktop installation is required. Create an independent Sonar account for the account/workspace features. Business-domain actions have additional verification requirements.

## Is this the application's source code?

No. This repository publishes documentation, examples and product references. The hosted backend, deployment configuration, credentials and private account data are not distributed here. The documentation/example [license](../LICENSE) does not grant access to private application source.

## Does Sonar replace every Ahrefs or Semrush feature?

No. Sonar does not maintain a global backlink index, global keyword-volume database or arbitrary competitor-traffic feed. Use the [comparison guide](https://pactuno.online/blog/sonar-vs-ahrefs-semrush) to choose by the job and evidence source.

## Does a score of 90 mean I will rank first?

No. The score describes Sonar's technical checklist for the fetched sample. It is not Google ranking or a prediction of visitors. [Methodology](METHODOLOGY.md).

## Is an orphan candidate definitely an orphan?

Not necessarily. A relevant linking page may be outside the sample or a link may be absent from original HTML but appear after JavaScript rendering. Verify the evidence and the visitor's expected route before fixing it.

## Why is a crawl smaller than 50 or 100 pages?

Those are maximum scopes. Robots rules, discovery, failures, supported scope and shared limits can reduce the actual sample. Read the report notes and date.

## Why is Google data unavailable?

Live Google integration depends on operator setup, permissions and provider quota. Local imports and official report workflows are separate. A connection screen is not evidence that real data has been fetched.

## Is the badge a security certificate?

No. It is a dated public record of an eligible technical sample and verification status. It can expire or become invalid. Limited owner-authorized security checks are not a full penetration test or continuous breach detection.

## How can I help?

Improve one guide, propose a useful example or report a reproducible issue. Follow the [first contribution guide](CONTRIBUTOR-QUICKSTART.md). Report vulnerabilities privately using [SECURITY.md](../SECURITY.md).
