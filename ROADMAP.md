# Sonar scope and roadmap

This is a direction, not a promise of delivery dates or unlimited service. The hosted product is early access. Check the live UI and current guides for availability.

## Current documented foundation

- On-demand original-HTML audits with single-page and bounded 50/100-page scopes.
- Affected-page evidence, technical findings and exports.
- Sample-based link/content review and supported rechecks.
- Independent Sonar accounts and verified business-domain workflows.
- Transparent technical scoring and expiring public badge records.
- A public documentation hub and practical articles in Pactuno's Blog.

## Improvements to prioritize

- Make the first audit, report state and next action clearer.
- Expand repeatable keyboard, mobile, light/dark and accessibility acceptance.
- Improve evidence provenance and provider-unavailable explanations.
- Strengthen crawl recovery, bounded resource use and report comparison.
- Keep setup examples, privacy wording and feature documentation aligned with the live service.

## Under consideration

- Broader rendering-aware coverage and larger crawl workloads, only with a sustainable resource model.
- Additional authorized data-source integrations and better source attribution.
- More guided workflows from a confirmed issue to a verified repair.

## Not promised

A global backlink/keyword-volume index, arbitrary competitor traffic counts, guaranteed Google positions, guaranteed AI recommendations, automatic website changes or continuous attack monitoring.
