# Your first contribution

You can help without paying for a tool or accessing anyone's private workspace.

1. Read the [README](../README.md) and choose one guide or example.
2. Check existing [issues](https://github.com/justokaywith/Sonar/issues) for related work.
3. Use GitHub's file editor or a local branch to make one focused documentation change.
4. Keep examples fictional. Use reserved example domains and placeholders, not real credentials or customer records.
5. Check relative links, headings, current UI labels and any screenshot you add.
6. Open a pull request using the [template](../.github/pull_request_template.md). Explain what became clearer and how you checked it.

## Useful small contributions

- Clarify a confusing step in [Quick start](QUICKSTART.md).
- Improve a troubleshooting answer in [FAQ](FAQ.md).
- Explain one evidence limitation with a concrete, fictional example.
- Report keyboard, contrast or mobile usability problems with redacted evidence.

Label documentation-only review versus an actual product test. Do not claim a provider connection worked unless you tested that connection.

This repository does not accept hosted backend source, deployment secrets, private scans, production logs or verification tokens. Security reports belong in the [private channel](../SECURITY.md).
